1. Purpose & Problem Statement

⚠️ Current Limitation (Local Dev Mode)

The app currently runs via shopify app dev on local machines using temporary Cloudflare tunnels. When the developer's laptop is closed or disconnects, the Node.js server shuts down, causing the app to become inaccessible to teammates, managers, and storefront shoppers.

✅ Desired State (24/7 Cloud Hosting)

Deploy the app container to a dedicated cloud server (Render / Railway). The server operates continuously 24/7/365 with zero dependence on any personal laptop. Teammates and clients can access the embedded admin and storefront sizing charts at any time.

2. Step-by-Step Deployment Procedure
1 Version Control & GitHub Repository Setup
Time: 3 Mins
Stage and commit all verified changes (remix admin UI, OS 2.0 theme extensions, and listing assets) to a private GitHub repository. 
# 1. Stage and commit all verified changes
git add .
git commit -m "feat: complete size chart app with app store proposal"

# 2. Link to private GitHub repository and push
git remote add origin https://github.com/Pixelotech/pixelotech-size-chart.git
git branch -M main
git push -u origin main
2 Automated Cloud Service Provisioning (Render / Railway)
Time: 7 Mins
Connect the GitHub repository to Render (Web Service) or Railway. Our repository already contains a production-ready Dockerfile that compiles and runs the app in production mode.

Configure the following Environment Variables in the hosting dashboard:

Environment Variable Production Value Purpose
SHOPIFY_API_KEY your_shopify_api_key Partner App Client ID
SHOPIFY_API_SECRET your_shopify_api_secret Partner App Client Secret
SCOPES read_products,write_app_proxy Required Shopify access permissions
HOST https://pixelotech-size-chart.onrender.com Permanent cloud service URL assigned by host
PORT 3000 Container listener port
3 Shopify Configuration & Extension Release
Time: 3 Mins
Update shopify.app.toml with the permanent cloud domain and release the extension build to Shopify's edge CDN: 
# Inside shopify.app.toml:
application_url = "https://pixelotech-size-chart.onrender.com"

[app_proxy]
url = "https://pixelotech-size-chart.onrender.com"
subpath = "size-chart"
prefix = "apps"

# In terminal: Deploy the production configuration to Shopify
npx shopify app deploy
4 Team Verification & Acceptance Checklist
Verification
  • Independence Check: Turn off all developer laptop terminals completely.
  • Admin Verification: Open POT App Test Store Admin — confirms the Size Chart dashboard and editor load instantly.
  • Storefront Verification: Visit pot-app-test-store.myshopify.com (Password: romeo) — verify popup/inline size charts display smoothly.
  • Continuous Deployment (CI/CD): Any future bug fix or feature pushed to main branch will auto-deploy without manual server steps.
